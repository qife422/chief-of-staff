
// ---------- Prompts: three small strict-format jobs, sized for a 270M model ----------
const SYS_PRIORITIES = `You are a chief of staff preparing a morning brief. From tomorrow's schedule and the user's brain dump, pick the 3 most important things for tomorrow. Output up to three lines and nothing else (fewer is fine if the input has fewer important things — never pad with invented items):

PRIORITY 1: <task, under 12 words> — <why it matters, under 12 words>
PRIORITY 2: <task> — <why>
PRIORITY 3: <task> — <why>

Rules: only use facts from the input. Never invent dates, names, or events.`;

// The priorities example travels as a prior conversation turn, NOT inside the
// system prompt, and this job runs GREEDY: with the example inline the 270M
// model parroted the example output verbatim for any input, and even as a
// turn, sampling fell back into repeating it in ~1/3 of runs (stress-tested
// 2026-10-23: inline+sampling echo 3/3, turn+sampling echo 3/9, turn+greedy
// echo 0/17). Replies and decision keep their examples inline + sampling —
// measured better there (replies via turn collapsed to 1 draft in 9/9 runs;
// decision via turn dropped its WHY line). Per-job settings are deliberate.
//
// 2026-10-25 real-input re-test (user's real Monday data): the turn+greedy
// priorities job STILL echoed the example's line 3 (landlord) — forcing
// exactly 3 lines makes the model pad with example content when the input
// covers fewer items. Fix: "up to three lines" (verified: echo gone, all
// lines from real input). Replies sampling collapsed to a bare "RE" with
// zero drafts on the same real input; replies now run GREEDY (verified:
// 1 draft to the right person). Decision stays inline + sampling: turn
// drops WHY and zero-shot emits only "DECISION:" — the inline example is
// load-bearing there, and its choice echo is a known model limitation,
// disclosed in the write-up rather than hidden.

REPLY TO <name or topic>: <draft reply, 1-2 short sentences>

Example:
Input: Messages: 1) Sarah (lab partner): "Did you finish your part of the lab report? It is due tomorrow." 2) Group chat: memes about the game. 3) TA for Prof. Lee: "Office hours moved to Thursday this week."
